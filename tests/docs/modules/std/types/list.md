# Type `std::List`

A globally available mutable ordered collection.

```exs
type List
```

## Implemented Methods

### `push(value)`

appends one value and returns the new length.

### `pop()`

removes and returns the final value, or None.

### `insert(index, value)`

inserts one value.

### `remove(index)`

removes and returns one value.

### `clear()`

removes every value.
